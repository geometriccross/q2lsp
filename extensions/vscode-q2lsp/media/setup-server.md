# Add q2lsp to your environment

QIIME 2 and q2lsp must be available in the **same Python environment**.

Choose **Prepare q2lsp** to check the interpreter you selected. If q2lsp is already available, no installation is needed.

If it is missing, review the Python path and confirm the installation. The extension runs pip with that interpreter, then checks the result.

The step is marked complete only after the check passes. Cancelling an installation leaves your environment unchanged.

For details or a failed installation, use [Show q2lsp Server Log](command:q2lsp.showServerLog).
