# Your QIIME 2 environment

q2lsp uses the Python interpreter inside your QIIME 2 environment.

## Already have QIIME 2?

Choose its Python interpreter. You can use the configured interpreter, the Python extension's selection, or browse to `bin/python` in your environment.

## Starting fresh?

Choose **Create a QIIME 2 environment**. Conda is the recommended option; Pixi and manual setup are also available. Distribution and version choices appear only when you create an environment.

Creating an environment downloads packages and may take a while. You'll confirm the target before anything is installed.

[QIIME 2 Quickstart](https://library.qiime2.org/quickstart/qiime2)

On Windows, open VS Code in **WSL** first.
